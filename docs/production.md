# 制作記録

## 企画

架空の旅行会社「余白旅行」。忙しい週末から、海辺や森の宿で何もしない時間へ移る60秒の縦型広告。中心コピーは「何もしない、をしに行こう。」。映像を多めに使いながら、問いかけとブランドメッセージは文字の場面で伝える。

## 素材制作・選定

生成動画候補から8本、静止画から2枚を採用した。生成指示・リファレンスの使い方は `generation-prompts.json`、元のファイル名は `../project/timeline.json` に保存している。生成指示は制作時の記録であり、同じ生成結果を再取得するための依存ファイルではない。再作成では保存済みの採用動画・写真を使用する。記録中の参照画像名には、不採用となり削除した制作時の画像も含まれる。

海辺・森の動画はそのままの情景を活かす。扉のシーンはV02の0.25–3秒、V07の0.5–1.75秒、V02の5–8秒を連結し、扉から海の情景へのつながりを構成する。人物をグリーンバックで別合成する工程は最終版では使用しない。

## 文字・配置

日本語だけで情報を構成し、英語のラベル、丸い帯、装飾的な角枠を撤去。文字の太さを確保し、文字の実際の描画範囲で中心位置を合わせた。余白は写真、コピー、ブランドの階層を分けるために使う。読点の送りは全角幅の0.55倍を基本に調整する。

確定した文字は透過PNGにし、行ごとに分割して短いフェードと最大12pxの上昇で表示する。文字の出現時間、位置、寸法は `motion` に記録。「予定でいっぱい？」は白文字と控えめな黒い影、下部の連続的な暗いグラデーションで読みやすくした。エンドは上部に海・森の写真、中央に主コピー、下部に紙飛行機のシンボルと「余白旅行」、その下に「あなたの週末に、余白を。」を置く。

PNGは承認済みの字形を固定する再作成素材。SVGは文字、配色、紙飛行機のベクター形状を残す編集元。フォントファイルの複製は含めない。

## 編集構成

| --- | --- |
| 0–3秒 | 週末への問い |
| 3–6秒 | 予定でいっぱい？ |
| 6–10秒 | 空いている時間まで |
| 10–17秒 | 扉・海辺の宿・扉の終点 |
| 17–23秒 | 次の週末は |
| 23–27秒 | 予定は、空白でいい |
| 27–31秒 | 森のなかで、深呼吸 |

映像の開始位置、拡大、切り抜き、写真の挿入、文字の合成は `../scripts/build.py` で実行する。エンドの2本は1.5倍の時間に伸ばして並べる。原素材の音声は使用せず、全編に連続した音声を合成する。

## 音響

`score.py` は固定シードを使った音楽合成。`atmosphere.py` は海・森の環境音と冒頭の時計音を合成する。音源ファイルの保存は不要で、毎回コードから作る。

35–39秒の音量を一律0.48倍にする処理と、同区間の音符を小さくする処理を削除した。35秒・39秒で急にゲインが切り替わる原因を取り除き、前後に続く音を維持した。最終ミックスには `loudnorm=I=-18:TP=-2:LRA=9` を適用し、48kHz・ステレオ・AAC 192kbpsで出力する。

## 出力・検証

各シーンを24fpsで描画し、結合した映像を高品質で一度書き出す。その映像を2パス・映像3050kbpsに圧縮し、修正済みの音声を合成する。この工程順を承認済みの最終版と合わせた。

全編のデコード、60秒・1440フレーム・1080×1920、48kHzステレオ音声、25,000,000 bytes未満を確認する。Gitに記録した一式を別フォルダへクローンして実際に再作成し、承認済みの動画と比較した結果は `../project/rebuild-verification.json` に保存する。

保存した最終版は承認済みファイルそのもの。旧版や未使用素材をGitの履歴に入れず、最終版に必要なデータだけで最初のコミットを作成する。
